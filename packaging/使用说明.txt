KUKA RSI POSCORR 位姿跟踪上位机
================================================================

这个目录是自包含的：Qt 的运行库都在里面，复制到任何一台 64 位
Windows 上都能直接双击运行，不需要装 Qt。


一、离线试用（不接机器人）
----------------------------------------------------------------

1. 双击  rsi_host.exe          —— 界面出来，状态栏显示「监听中」
2. 双击  启动模拟器.bat        —— 一个假的 KUKA 控制器开始发帧
3. 状态栏变成「已连接」，读数显示模拟器的位姿
4. 勾选顶部的「使能跟踪」
5. 拖 X 滑块，或直接改 X 数值框，加个 5mm

机器人（模拟器）会跟过去，误差曲线弹起一个峰再衰减回 0，
「目标 / 当前实际」两列会重新对齐。

想看安全保护动作：把 X 一次加到超过累积上限，状态栏会出现
「故障: displacement from session anchor ... exceeds limit」，
勾选框自动取消，机器人立刻停住。


二、状态栏三种状态的含义
----------------------------------------------------------------

  ○ 未监听              UDP 端口没绑上。多半是端口被占（上次的
                        程序还开着）。改个端口再点「开始监听」。

  ◐ 监听中（等待 KRC）  端口绑好了，但一帧都没收到。检查对面的
                        KRL 程序跑没跑、IP 和端口对不对。

  ● 已连接              正在收发。


三、接真机之前必须做的事
----------------------------------------------------------------

1. 改 config\rsi_config.json 里的累积上限。

   当前值 1000mm / 100° 是给模拟器调试用的。模拟器不实现 RSI 侧
   的任何限值，真机有：

       Limit 对象      ±35 mm / ±35°
       POSCORR         ±40 mm / 40°
       POSCORRMON      45 mm / 45°

   主机侧必须比它们都小，否则第一个拦你的会是 RSI 自己 —— 表现
   为机器人直接报错停机，而不是界面上一条可控的故障提示。

   首次联机建议：accum_limit_pos_mm = 10，accum_limit_rot_deg = 5

2. 把 kp 调到 0.1，限速调到 10 mm/s、2 °/s。

3. krc\ 里的四个文件要放到控制器上：

       PoseTrack.src           -> KRC:\R1\Program\
       PoseTrack.rsi           -> C:\KRC\ROBOTER\Config\User\Common\SensorInterface\
       PoseTrack.rsi.xml       -> 同上
       PoseTrack_ethernet.xml  -> 同上

4. 确认这四个值两边一致，尤其是第三个：

       上位机 IP   PoseTrack_ethernet.xml 的 <IP_NUMBER>  = 界面「监听地址」
       端口        <PORT>                                  = 界面端口
       SENTYPE     <SENTYPE>                               = rsi_config.json 的 sen_type
       小数位      PoseTrack.rsi.xml 的 Precision=4        = 上位机固定 4 位

   SENTYPE 不一致最阴险：界面会显示「已连接、丢包 0」，而 KRC
   那边一帧回包都没收下，最后以 RSI 超时停机收场。

5. T1 模式，手放在急停上，X 先只加 2mm。

详细步骤见项目里的 docs\deployment.md。


四、两个必须记住的限制
----------------------------------------------------------------

* 界面上的「停止跟踪」是软停止，不是急停。
  它把目标拉回当前位姿让机器人停住，但仍在持续回包 ——
  一旦停止回包，RSI 会判通信故障并报错停机。
  真正的急停只有示教器上的物理急停按钮。

* POSCORR 是叠加在当前位姿上的小幅实时修正（几十毫米量级），
  不是把机器人从 A 点搬到 B 点的工具。目标位姿应该在当前位姿
  附近微调。大范围运动请用 KRL 的 PTP / LIN。


五、目录里都是什么
----------------------------------------------------------------

  rsi_host.exe          上位机主程序（双击运行）
  krc_simulator.exe     假控制器，命令行工具
  启动模拟器.bat        用常用参数调起上面那个
  config\               配置文件，改完重启 rsi_host 生效
  krc\                  要部署到 KUKA 控制器上的四个文件
  platforms\ styles\    Qt 插件，别删
  Qt6*.dll libgcc*      运行库，别删
